# Finance 1.2.1 runtime write fix

Finance 1.2.1 fixes Joomla DatabaseInterface calls that passed temporary `(object)` expressions directly to `insertObject()` / `updateObject()`. Joomla drivers accept the object argument by reference, so affected operations could fail at runtime even though installation and syntax validation succeeded.

Affected paths fixed in 1.2.1:
- payment allocation insert;
- obligation status update after allocation;
- deposit account creation;
- budget creation;
- budget line creation.

The public Finance service API, idempotency keys, database schema and financial ownership boundaries are unchanged. Real runtime regression coverage executes the affected writes on Joomla 4.4.14, 5.4.8 and 6.1.3.
